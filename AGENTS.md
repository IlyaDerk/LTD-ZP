# Правила сопровождения

- Репозиторий — единственный источник рабочей логики Apps Script.
- Не коммитить OAuth-токены, `.clasprc.json`, пароли и иные секреты.
- Перед изменением расчёта сверять заголовки и справочники тестовой таблицы `Goal Зарплаты ЛТД`.
- Не публиковать код в Apps Script без отдельного подтверждения владельца.
- Не изменять строки со статусом `PAID` и не выполнять merge в `main` автоматически.
