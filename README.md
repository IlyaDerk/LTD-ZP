# LTD payroll MVP

Привязанный Google Apps Script для идемпотентного расчёта выплат и интерфейса собственника в тестовой книге **Goal Зарплаты ЛТД**.

## Модель работы

- `src/Core.js` проверяет сделку целиком и рассчитывает выплаты без Google API.
- `src/Sheets.js` читает книгу по заголовкам и записывает только изменившиеся полностью рассчитанные выплаты.
- `src/Main.js` выполняет синхронизацию под общей блокировкой и проверяет ID контейнера; `setup()` не создаёт триггеры.
- `src/OwnerCore.js`, `src/Owner.js`, `src/Sidebar.html` реализуют фильтры, выбор статей и двухшаговое атомарное подтверждение оплаты.
- `test/` содержит независимые от Google unit-тесты.

Если в сделке найдена хотя бы одна ошибка, ни одна её выплата не создаётся. Все причины собираются в `skippedDeals`, выводятся через `console.warn`, а остальные сделки продолжают рассчитываться. Диагностических статей и отдельного runtime-листа уточнений нет.

Внутри кода используются статусы `PLANNED`, `TO_PAY`, `PAID`, `CANCELLED`; в Google Sheets записываются соответственно `Запланировано`, `К оплате`, `Выплачено`, `Отменено`.


## Подготовка Apps Script

1. Скопировать `.clasp.json.example` в игнорируемый Git файл `.clasp.json`.
2. Авторизовать clasp локально, не публикуя `.clasprc.json` и OAuth-токены.
3. После отдельного разрешения владельца выполнить `npm run push`.
4. Перезагрузить таблицу и открыть меню «Зарплаты» → «Открыть интерфейс».

`setup()` проверяет обязательные листы, заголовки и ID контейнера без записей и без создания триггеров. Простой `onOpen()` добавляет меню, `onEdit(e)` обслуживает только выбор в интерфейсе. Старые триггеры standalone сохраняются до отдельного переключения владельцем.

Инструкция, безопасность подтверждения и порядок переключения: [Интерфейс собственника](docs/OWNER_INTERFACE.md). «На кассу» не реализуется на этом этапе. Факт выплаты в живой таблице тестируется только с отдельным разрешением на конкретные статьи.

Подробности: [`docs/ALGORITHM.md`](docs/ALGORITHM.md), [`docs/AUDIT.md`](docs/AUDIT.md), [`docs/DECISIONS.md`](docs/DECISIONS.md), [`docs/PROGRESS.md`](docs/PROGRESS.md).
