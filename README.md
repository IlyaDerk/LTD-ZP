# LTD payroll MVP

Standalone Google Apps Script для идемпотентного расчёта статей зарплаты из тестовой книги **Goal Зарплаты ЛТД**.

## Архитектура

- `src/Core.js` — чистое расчётное ядро без Google API;
- `src/Sheets.js` — чтение листов по заголовкам, преобразование матриц и запись только изменившихся строк;
- `src/Main.js` — блокировка, ежедневная синхронизация, оплата по чекбоксу и `setup()`;
- `test/` — независимые от Google fixtures и тесты.

Ставки, сотрудники, статьи и доли читаются из книги. В коде закреплена только подтверждённая семантика условий (структура из двух/трёх актов, получатель, готовность и выбор базы).

## Локальная проверка

```bash
npm test
npm run lint
```

## Подготовка Apps Script (после разрешения владельца)

1. Скопировать `.clasp.json.example` в `.clasp.json` (файл игнорируется Git) и не менять `scriptId`.
2. Авторизовать `clasp` локально, не коммитя `.clasprc.json`.
3. Выполнить `npm run push` только после отдельного разрешения владельца.
4. В редакторе standalone-проекта один раз вручную запустить `setup()` и подтвердить разрешения.

`setup()` проверяет доступ и обязательные заголовки, затем идемпотентно создаёт ежедневный и устанавливаемый edit-триггеры. Публикация и запуск `setup()` в рамках текущего изменения не выполнялись.

Подробная схема: [`docs/ALGORITHM.md`](docs/ALGORITHM.md), аудит книги: [`docs/AUDIT.md`](docs/AUDIT.md).
