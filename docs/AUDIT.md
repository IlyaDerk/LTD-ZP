# Read-only аудит книги Goal Зарплаты ЛТД

Дата: 2026-09-03. Источник данных — публичный Google Visualization CSV endpoint каждого листа. Запрошенный XLSX export отвечает редиректом на `googleusercontent.com`, который блокируется сетевым proxy контейнера; URL `/edit` как машиночитаемый источник не использовался. Книга не изменялась.

## Форматы и проверки данных

CSV подтверждает отображаемые форматы: даты `dd.mm.yyyy`, рубли, проценты и булевы значения. Формулы и правила dropdown/data validation формат CSV не передаёт; из-за блокировки конечного XLSX-хоста их нельзя доказательно инвентаризировать из контейнера. Код не удаляет существующие столбцы или пользовательские данные листа выплат.

## Расхождения и решения

1. Правила ремонта формулируют создание как «Ремонт подписан», но Goal требует подготовить статью сразу. Ядро создаёт бонус заранее как `PLANNED`, а дату ремонта использует только для готовности.
2. Для развёрток существует только правило Тамбова. Выбранные развёртки сотрудника другой модели переводятся в `NEEDS_REVIEW`, ставка не предполагается.
3. Матрицы не содержат периодов действия. Сейчас выбирается единственная активная строка; исторический выбор сотрудника поддержан, а неоднозначная ставка блокирует статью.
4. Существующие русские статусы нормализуются при чтении в канонические `PLANNED`, `TO_PAY`, `PAID`, `NEEDS_REVIEW`, `CANCELLED`.
5. Лишний столбец `Корректирует статью` автоматически не удаляется, поскольку в книге уже есть пользовательская структура; корректирующие статьи код не создаёт.
