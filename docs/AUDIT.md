# Аудит структуры книги Goal Зарплаты ЛТД

Дата исходного read-only аудита: 2026-09-03. Код не удаляет листы, столбцы, пользовательские строки или data validation.

## Обязательные runtime-листы

| Лист | Использование |
|---|---|
| Выгрузка сделок | Получение базы, структуры двух/трёх актов, получателей и дат готовности |
| Справочник сотрудников | Единственная действующая запись, модель, грейд и период действия |
| Справочник статей | Фильтрация активных видов выплат |
| Правила создания статей | Правило, получатель, код статьи и доля |
| Матрица Мотив Москва | Единственная ставка по грейду или бонусу |
| Матрица Мотив Тамбов | Единственная ставка по работе, пакету и грейду |
| Статьи оплаты | Чтение существующих и запись полностью рассчитанных выплат |

Листы `На уточнении` и `Интерфейс собственника` могут оставаться в книге, но их отсутствие не блокирует `setup()` или синхронизацию. Код их не создаёт, не очищает и не обновляет.

## Совместимость существующей структуры

- `Причина уточнения` больше не требуется, не читается и не заполняется. Если столбец уже существует, запись строки сохраняет его текущее значение.
- `Оплатить` не требуется на стадии preflight. После успешной проверки `setup()` добавляет его, только если столбца нет.
- Существующая data validation не удаляется; обработчик изменяет только checkbox, статус, дату выплаты и время обновления.
- Дополнительные пользовательские столбцы, включая `Корректирует статью`, сохраняются.

## Контроль качества данных

Сделка полностью пропускается при неоднозначной структуре, отсутствующем получателе, нуле или нескольких действующих сотрудниках, неизвестной модели, пустом грейде, неположительной базе, нуле или нескольких ставках, отсутствии/дублировании ожидаемого правила либо невозможности применить правило развёрток. Частичные выплаты по ошибочной сделке не записываются.
