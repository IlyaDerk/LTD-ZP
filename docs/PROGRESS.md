# Журнал работы

## 2026-09-03 — исходный MVP

- Реализованы расчётное ядро, адаптер Google Sheets, блокировка, обработчик оплаты и настройка триггеров.
- Создан тестовый standalone Apps Script и выполнена первая разрешённая публикация пяти файлов.
- Deployment не создавался, `setup()` и `dailySync` не запускались, таблица не изменялась.

## 2026-09-03 — упрощение обработки ошибок

- Диагностические статьи и статус уточнения удалены из runtime-модели.
- Сделка с любой ошибкой теперь пропускается целиком; причины агрегируются, логируются и возвращаются из `dailySync`.
- Добавлены предварительные проверки структуры, получателей, сотрудника, модели, грейда, базы, единственности ставки и правила развёрток.
- Статусы при записи в Sheets переведены на `Запланировано`, `К оплате`, `Выплачено`, `Отменено`; внутренние сравнения оставлены английскими.
- Удалена обязательность листов `На уточнении`, `Интерфейс собственника` и столбца `Причина уточнения` без их физического удаления.
- `setup()` перестроен в последовательность preflight → checkbox → ровно по одному целевому триггеру.
- Добавлены тесты атомарного пропуска сделки, продолжения расчёта, нескольких причин, отсутствия диагностических статусов, русских статусов, оплаты и идемпотентности.

## Следующий шаг после merge/review

После отдельного разрешения опубликовать в тестовый Apps Script обновлённые `Config.js`, `Core.js`, `Main.js`, `Sheets.js` и неизменный `appsscript.json`. Затем отдельно разрешить и вручную выполнить `setup()`, после чего провести контролируемые запуски `dailySync` на тестовой книге.

В рамках этой доработки `clasp push`, `setup()` и `dailySync` не выполняются.
